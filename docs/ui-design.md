# 学習ノートのUI設計

2026-11-07。既存のNext.js／React／CSS／Rechartsを使用。依存追加なし。

## 課題

- 淡い色の8〜11pxの補助文字が多く、日本語の読み取りが難しい。
- 同形のカードと装飾文が情報の重要度を曖昧にしている。
- 記録一覧がページ下部にあり、教材・カレンダーへ直接移動できない。
- ナビゲーションの選択表示が常にダッシュボードのまま。
- スマホではナビゲーションがアイコンのみで、一覧は横方向に読ませる構成。

## 設計原則と参照

ユーザー提供の `skills-main.zip` 内 `skills/frontend-design/SKILL.md` を読み、設計→見直し→実装→実画面の批評の順で作業。

- [Notion](https://www.notion.com/en-gb/help/navigate-with-the-sidebar): 情報の行き先を明確にし、本文の領域を優先。
- [Linear](https://linear.app/now/behind-the-latest-design-refresh): ナビゲーションを控えめにし、操作位置を一定に保つ。
- [Things](https://culturedcode.com/things/features/): 一覧の文字組みと余白によって内容と補足を読み分ける。

参照製品の見た目をコピーせず、学習時間・教材・日本語の記録を読むためのUIとして再構成。

## トークン

|役割|値|
|---|---|
|本文|`#24282f`|
|補助文字|`#626b78`|
|操作・選択|`#315da8`|
|本文背景|`#ffffff`|
|ナビゲーション・補助面|`#f5f6f8`|
|区切り|`#e2e5ea`|

日本語はYu Gothic UI／Hiragino Sans／Noto Sans JP／Meiryoのローカルフォント。本文14px、一覧13〜14px、補助11〜12px、節見出し16〜20px、ページ見出し26〜30px。数値は等幅数字。文章は左揃え、長い説明は約60〜75ch。

余白は4／8／12／16／24／32pxを基本とする。操作は5px、補助面6px、ダイアログ10pxの角丸。通常面は影なし、重なりを示すダイアログのみ影を使う。教科色は既存の安定した割り当てを維持し、グラフ・教科識別にだけ使う。

## 構造

```text
固定ナビゲーション  | 学習ノート                 共有 / 記録する
概要                | 期間 / 教科 / 教材 / 更新
学習記録            | 週の数値（ひと続きのサマリー）
教材                | 週目標と進捗
カレンダー          | 日別グラフ / 教科内訳
学習の推移          | 学習記録の一覧
                    | 教材の比較 / カレンダー / 8週間の推移
```

案の見直し：数値カード3枚＋装飾的な励ましのパネルは汎用ダッシュボードに見えるため不採用。数値を一続きの欄にし、説明的な見出しと実データで階層を作る。週間グラフの装飾グラデーションも単色に置き換える。

スマホでは上部に文字付きナビゲーションを固定。一覧は日付・教科・時間の行と、学習内容・教材の行に組み直し、テーブルとしてのアクセシビリティを維持。多列の教材比較だけは横スクロールにする。

## 操作と保全

- 現在の節をナビゲーションに反映し、キーボードフォーカスと本文スキップを用意。
- カレンダーで日を選んだ後は日別レポートへ、教材を選んだ後はフィルターが見える先頭へ移動。
- 月／週／期間、教科、教材、並べ替え、ページ送り、記録、目標、共有を維持。
- ログイン、閲覧専用、空表示、同期エラー、入力ダイアログにも同じルールを適用。
- モバイルの主な操作は44px以上。動きを減らすOS設定を尊重。
- API、認証、集計、キャッシュ、Notionへの保存処理、既存データを変更しない。

実画面の検証結果は `VERIFICATION.md` を参照。
